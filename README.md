# Локатор

Telegram-бот с картой (Mini App), в котором друзья видят геопозицию друг друга в реальном времени.

- **В фоне** геопозицию передаёт сам Telegram: человек отправляет боту «трансляцию геопозиции», и бот получает каждое её обновление с точностью GPS. Отдельное приложение ставить не нужно.
- **Пока открыта карта**, она дополнительно передаёт точные GPS-координаты телефона каждые 2 секунды (с точностью, направлением и скоростью).
- **Только по взаимному согласию:** друг открывает вашу ссылку и соглашается, вы подтверждаете запрос. Скрыться (`/pause`), удалить друга или стереть свои данные (`/forget`) можно в любой момент.
- Хранится только последняя точка каждого человека, истории перемещений нет.

## Запуск

Нужен [Node.js](https://nodejs.org) 22.13 или новее. Устанавливать зависимости не нужно.

1. Создайте бота у [@BotFather](https://t.me/BotFather) командой `/newbot` и скопируйте токен.
2. Скопируйте `.env.example` в `.env` и впишите токен в `BOT_TOKEN`.
3. Запустите:

   ```
   npm start
   ```

Бот уже работает: `/start`, `/invite`, `/friends`. Чтобы появилась карта, серверу нужен публичный HTTPS-адрес — укажите его в `PUBLIC_URL` и перезапустите бота. Кнопка «Карта» появится в меню бота сама.

Попробовать карту без своего домена можно через временный туннель:

```
cloudflared tunnel --url http://localhost:3000
```

Он выдаст адрес вида `https://….trycloudflare.com` — его и нужно вписать в `PUBLIC_URL`.

### Docker

```
docker build -t lctr .
docker run -d --restart unless-stopped -p 3000:3000 -v lctr-data:/data \
  -e BOT_TOKEN=... -e PUBLIC_URL=https://ваш-домен lctr
```

База данных лежит в томе `/data`. HTTPS должен обеспечивать прокси перед контейнером (Caddy, nginx) или хостинг.

## Как добиться максимальной точности

- Включайте трансляцию «Пока не отключу»: 📎 → «Геопозиция» → «Транслировать мою геопозицию».
- В настройках телефона дайте Telegram доступ к геопозиции «Всегда» и включите «Точную геопозицию».
- На Android отключите для Telegram экономию заряда, иначе система будет приостанавливать его в фоне.
- Когда нужна точность до метров прямо сейчас — откройте карту: пока она открыта, координаты идут напрямую с GPS.

Точность в фоне и частоту обновлений определяют Telegram и телефон: обычно это 5–20 метров на улице, а обновления приходят по мере движения.

## Команды бота

| Команда | Что делает |
| --- | --- |
| `/map` | Карта с друзьями |
| `/friends` | Где сейчас друзья, показать точку, удалить друга |
| `/invite` | Ссылка-приглашение (её можно сбросить) |
| `/share` | Как включить трансляцию; отправить одну точку |
| `/pause`, `/resume` | Скрыть и снова показывать свою геопозицию |
| `/forget` | Удалить все свои данные |

## Тесты

```
npm test
```

Тесты поднимают бота целиком и разговаривают с ним через имитацию Telegram API (`test/fake-telegram.js`).

## Устройство

| Файл | Назначение |
| --- | --- |
| `src/service.js` | Правила: кто кого видит, друзья, пауза, приём точек |
| `src/bot.js` | Диалог в Telegram |
| `src/web.js` | Сервер карты: API, поток обновлений, статика |
| `src/auth.js` | Проверка подписи Telegram и сессии карты |
| `public/` | Карта (Leaflet + OpenStreetMap) |
